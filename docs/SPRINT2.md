# Sprint 2

Product shell, experience permissions/connections, search, and ecosystem directory foundations.

## New capabilities

- Experience connect / permission consent / disconnect
- Scoped experience sessions (no TrustID tokens to businesses)
- BusinessDirectoryProvider + ExperienceProvider
- Global search (`/search`)
- Connected experiences UI
- Preferences API
- Notification categories + mark-all-read
- Activity deep links
- LifeOS audit events
- Design system expansions (Card, Sheet, Skeleton, Avatar, …)

## Run

```bash
npm run setup
npm run dev
npm test
```
