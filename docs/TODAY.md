# Today

`/app/plans` is LifeOS’s **Today** destination (nav label: Today).

## Sections

1. **Needs attention** — prioritized view over notifications + failed/pending actions
2. **Continue** — unfinished ActionRecords (no payment credentials)
3. **Today** — timed items for the current day with contextual actions
4. **Tomorrow / This week / Upcoming**
5. **Completed**
6. **Saved** → `/app/saved`
7. **For you** — deterministic recommendations
8. Optional **Timeline** toggle (orientation, not a full calendar)

## Contextual actions

| Item | Example action |
|------|----------------|
| Appointment | View |
| Stay / Class | Check In |
| Ticket / Event | View Ticket |
| Payment attention | Pay |
| Default | Open |

## Calendar-like orientation

Supports Today · Tomorrow · This Week · Upcoming — not calendar management (no invites, sync engines, or conflict scheduling).
