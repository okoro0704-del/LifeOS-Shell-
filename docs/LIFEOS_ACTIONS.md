# LifeOS Actions

User journey:

DISCOVER → VIEW → CHECK AVAILABILITY → SELECT → REVIEW → CONFIRM → COMPLETE → RETURN

Results use `ActionResult` statuses: SUCCESS, PENDING, FAILED, CANCELLED, REQUIRES_AUTHORIZATION.

Plans (`/app/plans`) and Saved (`/app/saved`) are LifeOS aggregation/read surfaces — not booking databases.
